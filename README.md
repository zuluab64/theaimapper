# The AIMapper - theaimapper.com

The marketing site for The AIMapper. Eight plain pages, one stylesheet,
one small script. No frameworks and no build step.

## Pages
| File | Page |
|------|------|
| `index.html` | Home |
| `approach.html` | Our Approach |
| `services.html` | Services & Pricing |
| `client-stories.html` | Client Stories |
| `about.html` | About |
| `scorecard.html` | Free AI Opportunity Scorecard |
| `contact.html` | Contact |
| `privacy.html` | Privacy (linked from the footer) |

## Folders
- `css/style.css` - all styling
- `js/site.js` - the menu button and the Scorecard
- `fonts/` - Newsreader, Inter, JetBrains Mono (saved with the site)
- `images/` - paintings, portrait and the sharing image
- `vercel.json` - caching rules

## Publishing
Changes pushed to the `main` branch on GitHub are published by Vercel.

## Where the rules live
The facts, copy and design rules are kept outside this folder, in
`CLAUDE Folder/AIMapper Redesign/` (CONTEXT.md, COPY.md, DESIGN.md).
